# laiayumi.github.io

Portfólio pessoal de **Laissa Ayumi**, desenvolvedora full stack.

Site publicado em: https://laiayumi.github.io

## Sobre o site

- Página única em HTML, CSS e JavaScript puros, sem build e sem dependências.
- Bilíngue (português e inglês), com botão PT/EN no topo.
- Seções: hero em carrossel, sobre, projetos com filtro, case da KIKA AI com simulação interativa, trajetória, números e contato.
- Os projetos profissionais são confidenciais: o site descreve problema, arquitetura e resultados sem expor código ou dados. A simulação usa tabelas e clientes fictícios.

## Como editar

Todo o conteúdo está em `index.html`. Cada texto aparece duas vezes, uma com `lang="pt"` e outra com `lang="en"`: altere as duas versões.

Para ver localmente, abra `index.html` no navegador ou rode:

```bash
python3 -m http.server 8000
```

e acesse http://localhost:8000.

## Publicação

O GitHub Pages publica automaticamente a branch `main`. Cada push atualiza o site em alguns minutos.
